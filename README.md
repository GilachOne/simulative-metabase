## Исследовательский вопрос

Как охват корпоративного обучения связан с практикой и новым прогрессом, как меняется активность после регистрации и какие задания требуют дополнительной проверки?

Дашборд последовательно показывает охват, динамику практики, распределение новых решений, когортное удержание и задания с высокой долей ошибочных сдач. Подробная аргументация и дополнительные разрезы приведены в отчёте.

По умолчанию выбраны компания 1 и 01.07.2021–30.04.2022 включительно. В этом срезе 133 студента, 126 посетителей и 97 студентов хотя бы с одним новым решением. «Новое решение» — первая успешная сдача пары студент–задача, а не любая повторная успешная попытка. События до регистрации исключены.

Когортная таблица отражает практику в календарные месяцы после регистрации. Ноль означает отсутствие практики, пустая ячейка — незавершённый период наблюдения. Малые когорты нельзя интерпретировать как устойчивую тенденцию.

## Практические задания

Расходы CodeCoins представлены горизонтальными столбцами. В rolling retention применена цветовая шкала отдельно к каждому столбцу.

В анализе источников URL разбирается на параметры по `&`, после чего проверяется точное имя параметра до `=`. Поэтому `source` и `utm_source` не смешиваются. Событие с несколькими разными источниками может попасть в несколько строк, и суммы по источникам не следует считать уникальными событиями всего сайта.

Воронка Роберта показывает количества событий шести типов, а не последовательную конверсию одних и тех же пользователей. Проценты на визуализации — отношение количества событий к входам на сайт; заявки и переходы не обязательно образуют строгую последовательность. Для события без URL используется последнее непустое значение параметров того же UID из прошлого. UID обозначает браузер, а не гарантированно отдельного человека. Фильтр источника принимает полную пару, например `discount=15`.

## Проверка

- Контрольный срез дашборда: 133 / 126 / 97 — соответствует отчёту.
- Компания 2 при том же периоде: 1 / 1 / 1.
- Компания 1, дата окончания 31.03.2022: 119 / 110 / 87. После проверки восстановлены исходные фильтры.
- Воронка без фильтров: 7323 / 2315 / 157 / 123 / 132 / 14 событий.
- Источник `discount=15`, январь 2023: 14 / 13 / 6 / 2 / 4 / 0 событий.

Данные исторические. Автообновление повторяет запросы, но не превращает учебную выборку в актуальные операционные данные.
